# myMakan Beta — Tester Guide

Thanks for helping test myMakan. This build is for **private testing only** —
please don't share the APK or the site outside this group.

## Installing the Android app

1. You'll receive an `.apk` file (not from the Play Store — this is a direct
   test install).
2. On your Android phone, open the file. If you see "blocked by Play
   Protect" or "install unknown apps," allow it for this one file — that
   warning is expected for a test build, not a sign anything is wrong.
3. Open the app once installed. The app talks to our live test server, so
   you'll need an internet connection.

## Creating an account

- Tap **Sign up**, enter an email and password. Use a real email you can
  check if the app ever asks you to reset your password.
- You can also test on the web version at the site link we shared with you.

## Suggested test flow

Try this once as a **Rent** search, then repeat as a **Buy** search:

1. Search for a property (try a city or area name).
2. Open a property's details page.
3. Ask the AI advisor a question about it.
4. Save the property.
5. Schedule a viewing.
6. Send an inquiry/message to the listing's mediator.
7. Make an offer (Buy) or continue through the viewing/negotiation flow (Rent).
8. Check the Transaction Workspace once an offer/negotiation is accepted.

Feel free to explore beyond this list — partner and admin features are also
part of this beta if you were given those credentials.

## Reporting issues

For anything that looks wrong, please tell us:

- **Screen** — where you were (e.g. "Property detail page")
- **Action** — what you did (e.g. "tapped Save")
- **Expected** — what you thought should happen
- **Actual** — what actually happened
- **Screenshot** — if possible
- **Device model** — e.g. "Samsung Galaxy S23"
- **Android version** — Settings → About phone → Android version

Send reports to the contact we gave you when sharing this build. Don't
include your password in any report.

## What's not in this beta

Contracts, ID verification, live payments, and financing aren't part of this
test — those come later. See the release notes if you want the full list.
